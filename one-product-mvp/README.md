# «Один товар» — MVP

Изолированный прототип товарного конвейера для «А Маркета». Не изменяет каталог, Telegram-публикации или синхронизацию цен.

## Что уже делает

- принимает основные данные и до 10 фотографий товара;
- формирует тексты для Telegram, Авито и Instagram;
- создаёт PNG-карточку 1080×1350;
- создаёт ценник 58×40 мм;
- формирует нормализованный JSON для будущей интеграции;
- хранит незавершённый черновик локально в браузере.

## Следующий этап после проверки

1. Авторизация продавца.
2. Запись товара в каталог сайта.
3. Отправка черновика или публикация в Telegram.
4. Экспорт официального файла автозагрузки Авито.
5. Обёртка того же сценария в Telegram-бота.

Автоматическая публикация в Instagram и Авито зависит от официального доступа конкретного бизнес-аккаунта. MVP не использует обходные методы и не хранит токены.
