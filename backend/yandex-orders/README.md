# А Маркет — безопасный приём заявок

Техническая часть подготовлена, но приём реальных заказов через Yandex Cloud **не включён**. Публичный файл `assets/orders-config.json` должен оставаться с пустым `apiUrl` до отдельного подтверждения владельца и завершения юридической проверки.

## Текущее состояние на 04.11.2026

- YDB Serverless `amarket-orders` создана в `ru-central1`, лимит хранения 1 ГБ, защита от удаления включена.
- Таблица `orders` создана по `schema.sql`.
- Сервисный аккаунт функции имеет ограниченные права на YDB и чтение только необходимых секретов Lockbox.
- Cloud Function `amarket-orders-api` развёрнута, но публичный вызов выключен.
- SmartCaptcha обязательна на сервере; проверяются ответ CAPTCHA и разрешённое имя сайта.
- Секрет администратора и серверный ключ CAPTCHA хранятся в Lockbox и не находятся в репозитории.
- Админ-ключ не сохраняется в localStorage, sessionStorage, cookie или URL — только в памяти открытой вкладки.
- Проверки фиктивного запроса, чужого Origin, отсутствия согласия и запроса администратора без ключа пройдены.
- На сайте опубликованы отдельное согласие и политика обработки данных. В корзине добавлено обязательное подтверждение согласия.
- В YDB есть одна синтетическая тестовая запись без реальных персональных данных.

## Защитные ограничения

1. Не добавлять URL функции в `assets/orders-config.json` без отдельного подтверждения владельца.
2. Не включать публичный вызов функции до финального сквозного теста.
3. Не помещать токены, ключи или персональные данные в GitHub, логи, Telegram или адресную строку.
4. Не переходить с Trial на платный режим без отдельного согласия владельца.
5. Уведомление в Telegram, если оно будет включено, должно содержать только номер заявки и количество позиций — без имени и телефона.
6. Цена из браузера является заявленной и требует подтверждения менеджером.

## Срок хранения и удаление

Для незавершённых заявок принят рабочий срок 90 дней. Подготовленный файл `retention.sql` сначала показывает кандидатов на удаление и содержит отключённый шаблон удаления. Автоматическое удаление не запускается до появления управления статусами заказа и отдельного подтверждения владельца. Завершённые заказы могут требовать иных сроков хранения по бухгалтерским и налоговым основаниям.

## Перед включением

1. Подтвердить статус уведомления оператора персональных данных в реестре Роскомнадзора.
2. Проверить актуальность политики, отдельного согласия, целей, перечня данных, сроков и порядка отзыва.
3. Провести финальный тест только на вымышленных данных: CAPTCHA → функция → YDB → закрытая админка.
4. Проверить журналы, лимиты, бюджет и отсутствие ПДн в логах/уведомлениях.
5. Только после этого по отдельному подтверждению владельца включить публичный вызов функции и указать URL в конфигурации сайта.

## Автоматические проверки

GitHub Actions `orders-backend-check.yml` проверяет синтаксис и обработчик без доступа к реальной YDB, секретам и реальным ПДн:

`python -m unittest discover -s backend/yandex-orders -p 'test_*.py' -v`

Успешные тесты не заменяют юридическую проверку и сквозной аудит безопасности.
