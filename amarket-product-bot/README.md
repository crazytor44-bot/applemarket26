# А Маркет · «Один товар»

Закрытый Telegram Mini App для добавления одного товара и подготовки материалов для Telegram, Авито и Instagram. Проект не размещается на сайте магазина и не меняет каталог `applemarket26.ru`.

## Готово в версии 0.1

- запуск формы прямо из `@amarket_product_bot`;
- карточка товара 1080×1350 из фотографии;
- тексты для Telegram, Авито и Instagram;
- публикация фотографии и текста в Telegram-канал;
- серверная проверка подписи `Telegram.WebApp.initData`;
- доступ к публикации только для Telegram ID из белого списка;
- токен хранится только как зашифрованный секрет хостинга.

## Что потребуется для запуска

1. Аккаунт Cloudflare и установленный Node.js.
2. В каталоге проекта выполнить `npm install`.
3. Войти: `npx wrangler login`.
4. Сохранить секреты командами:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
npx wrangler secret put ALLOWED_USER_IDS
```

Канал `@applemarket26` уже указан в конфигурации. `ALLOWED_USER_IDS` — цифровые Telegram ID владельца и продавца через запятую. Случайный человек не сможет публиковать товары.

5. Развернуть: `npm run deploy`.
6. Не отправляя токен в чат, запустить локально настройку Telegram:

```bash
TELEGRAM_BOT_TOKEN="..." WEBHOOK_SECRET="..." WORKER_URL="https://адрес-воркера" npm run setup
```

После `/start` бот показывает цифровой Telegram ID пользователя. Его нужно добавить в `ALLOWED_USER_IDS` и повторно сохранить секрет.

## Безопасность

- Не коммитьте `.dev.vars`, `.env` или токен.
- Добавьте `@amarket_product_bot` администратором канала только с правом публикации сообщений.
- При утечке токена немедленно перевыпустите его через `@BotFather`.
- Кнопка публикации требует дополнительного подтверждения внутри Mini App.
