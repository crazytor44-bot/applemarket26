# Автономные публикации в Telegram

Владелец канала дал постоянное разрешение на самостоятельную подготовку и публикацию оригинальных материалов в 09:00, 15:00 и 20:00 по Москве. Для каждого слота создаётся один файл `telegram_channel/post_queue/YYYY-MM-DD-slug.json`; отдельное согласование не требуется. Запрещено выдумывать цены, наличие, гарантии и новости. Сайт, прайс и их синхронизация этим контуром не изменяются.

Пример структуры (не создаёт публикацию):

```json
{
  "approved": true,
  "channel": "@applemarket26",
  "publish_at": "2026-10-20T09:00:00+03:00",
  "text": "Точный текст, утверждённый владельцем",
  "parse_mode": "plain",
  "pin": false,
  "photo_repository_path": "telegram_channel/media/approved-poster.jpg",
  "photo_git_blob_sha": "SHA1 Git blob оригинального утверждённого фото"
}
```

Фото кладём в `telegram_channel/media/` только когда оно действительно улучшает публикацию. Без подтверждённого SHA, отметки `approved=true` или нужного времени **ничего не отправляем**. Значение `approved=true` означает разрешение в рамках постоянного поручения владельца, а не отдельное согласование каждого поста.

При создании JSON проверка стартует сразу, но отправка произойдёт **не раньше `publish_at`**. Отдельный workflow раз в ~10 минут в дневное время Москвы (08:00–20:59) подхватывает готовые посты. GitHub Actions может задержать cron, **точность до минуты не гарантируется**. Можно запустить workflow вручную (Run workflow), он опубликует только уже наступившие утверждённые посты.

Чтобы не было повторов, перед отправкой создаётся атомарная запись `telegram_channel/post_receipts/<имя>.json`. Если запись уже существует, второй раз не отправляем. После успешной отправки сохраняются ID и прямая ссылка, затем сообщение проверяется на публичной странице канала. Статус `verified_public` означает, что квитанция и фактическое сообщение подтверждены; `published_unverified` требует ручной проверки и не допускает автоматического повтора. Если связь с Telegram оборвалась и неизвестно, дошло ли сообщение, **автоматических повторов нет**. Синхронизацию цен не меняем.

Локальная безопасная проверка: `python3 telegram_channel/post_queue.py --check`.
