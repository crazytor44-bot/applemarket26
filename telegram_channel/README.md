# А Маркет — Telegram-канал @applemarket26

Этот модуль **независим от существующей синхронизации прайса с Telegram**.
Он не читает личные переписки и не использует `TELEGRAM_SESSION`.

## Бесплатный запуск

GitHub Actions на стандартном runner `ubuntu-latest` в нашем **публичном**
репозитории выполняется бесплатно (в пределах применимых правил GitHub).

1. Открыть в Telegram официального `@BotFather`, выполнить `/newbot`.
   Выбрать имя и свободный username, оканчивающийся на `bot`.
2. В канале **@applemarket26**: Управление каналом → Администраторы →
   Добавить администратора → выбрать нового бота.
   Разрешить **публиковать сообщения** и **изменять информацию канала**.
   Не предоставлять лишние полномочия.
3. В репозитории `crazytor44-bot/applemarket26` открыть
   **Settings → Secrets and variables → Actions → New repository secret**.
   Имя секрета: `AMARKET_TELEGRAM_BOT_TOKEN`. Значение — token от BotFather.
   **Никогда не публикуйте токен в чате, файлах репозитория или скриншотах.**
4. Когда данная ветка будет объединена с `main`, перейти на
   **Actions → A Market Telegram content → Run workflow → check**.
   После успешной проверки выполнить **Run workflow → brand**.
   Это обновит только название и описание канала, сохранив @applemarket26
   и подписчиков. Аватар и старые посты не меняются.

## Как будем публиковать

1. Ассистент готовит текст и картинку **и показывает владельцу канала**.
2. Владелец пишет, что **одобряет конкретный пост**.
3. Только после этого ассистент добавляет новый файл
   `telegram_channel/approved/2026-10-15-example.json` в `main`.
4. Добавление такого файла автоматически запускает GitHub Actions и
   публикует **только добавленный файл**. Редактирование старых не публикует
   их повторно. Повторный запуск workflow отключён, чтобы избежать дублей.

Пример файла:

```json
{
  "text": "<b>А Маркет 🔥</b>\nНовинки и интересные предложения.\n📍 Тухачевского, 16",
  "parse_mode": "HTML",
  "photo_url": "https://example.com/public-image.jpg"
}
```

Для публикации без картинки убрать поле `photo_url`.
HTML-разметка поддерживает `<b>`, `<i>`, `<a href="...">` и др.
Амперсанды и угловые скобки в тексте нужно экранировать.
Картинка должна иметь доступный извне HTTPS-адрес.

**Важное ограничение:** Telegram Bot API не гарантирует идемпотентность.
Если сообщение успело уйти в канал, но сеть оборвалась до подтверждения,
автоматический повтор может создать дубль. Мы намеренно отключили
повторные попытки действий публикации.

**Безопасность:** файлы постов в публичном репозитории доступны всем —
размещаем в них только рекламный, уже одобренный для публикации контент.
На ветке `main` изменения существующей синхронизации прайса не требуются.
