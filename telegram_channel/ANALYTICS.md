# Telegram analytics — А Маркет

## Где смотреть

[GitHub Actions → A Market Telegram analytics](https://github.com/crazytor44-bot/applemarket26/actions/workflows/telegram-analytics.yml):
открыть последний успешный запуск → **Summary**. Здесь показаны
подписчики, просмотры и реакции последних публичных постов.
В **Artifacts** доступны JSON и Markdown (хранятся 90 дней).

Проверка автоматически запускается приблизительно в 08:00, 14:00 и
20:00 по Ставрополю (планировщик GitHub может задерживать запуск).
Для немедленной проверки: **Run workflow**.

Мы не читаем личные сообщения и не пытаемся определять личности зрителей
или ставивших реакции — Telegram не передаёт такие списки для каналов.

Скрипт работает с открытым предпросмотром `https://t.me/s/applemarket26`
и `getChatMemberCount` Telegram Bot API. **Не вызывает getUpdates**, чтобы
не мешать текущим интеграциям бота и магазину. Отчёт содержит только
агрегированные счётчики. Если Telegram скроет счётчики или изменит
HTML-верстку, часть данных будет помечена прочерком, а не выдумана.
