Доступ к публикации не подключён

Проверить расчёт можно без ключа. Для публикации нужен ключ GitHub только к репозиторию сайта.

Ключ остаётся в памяти этой вкладки и отправляется только GitHub. После перезагрузки его нужно ввести снова. Не присылайте ключ в переписку.

Как создать ключ — один раз
  1. Откройте создание ключа GitHub ↗ под аккаунтом владельца сайта.
  2. Выберите Only select repositories и репозиторий applemarket26.
  3. В Repository permissions → Contents установите Read and write. Задайте срок действия.
  4. Создайте ключ, скопируйте его и вставьте в поле выше.

Если ключ не даёт права записи, публикация будет отклонена.

1. Прайс поставщика

Закупочные цены используются только для расчёта в этой вкладке. На сайте появятся розничные цены.

Товары, которых нет в присланном прайсе, сохранятся. Новые модели, цвета, заметки о состоянии и сроки поступления автоматически не добавляются.
