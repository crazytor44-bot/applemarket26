# Редактор прайса А Маркет

Адрес: `/admin/prices/`. Страница не связана с меню магазина и исключена из индексации метатегом robots. Это публично доступный интерфейс; запись в репозиторий защищена авторизацией GitHub, а не секретностью адреса.

Порядок работы: вставить прайс → проверить → выбрать строки → подтвердить → опубликовать. Обычная наценка по умолчанию 1990 ₽. Предзаказы отключены по умолчанию, их наценка 4990 ₽ задаётся отдельно. Редактор обновляет только существующие точно совпавшие варианты. Он не меняет остатки, сроки, состояние, состав каталога или фотографии. Пропавшие из прайса позиции не удаляются. Дубли, неоднозначные совпадения и неизвестные варианты исключаются. Изменения больше 20% требуют дополнительной отметки.

Для записи пользователь вводит fine-grained GitHub token с доступом только к `crazytor44-bot/applemarket26`, Repository permissions / Contents / Read and write. Ключ хранится только в памяти вкладки и отправляется только `api.github.com`. Аналитики и сторонних скриптов на странице нет. Исходный прайс и закупочные цены не отправляются в репозиторий; в изменяемые файлы попадают итоговые розничные цены. Подключение не подтверждает права записи — окончательную проверку выполняет GitHub при публикации.

Публикация строит одно дерево и один коммит относительно проверенного состояния main. Затем ссылка main обновляется без force. При изменении main проверку надо повторить. Обновляются embedded catalog-data, статические карточки, product-data и минимальные цены на страницах iPhone, главная, ссылки WhatsApp и yml.xml. GitHub Pages публикует коммит; интерфейс проверяет появление новых цен на публичном каталоге. При сетевой ошибке после отправки сначала проверьте каталог и историю коммитов.

Корзина повторно сверяет цены перед оформлением. Если сумма изменилась, требуется ещё раз нажать оформление после просмотра нового итога.

Тесты: `cd tests && npm install && npm test`. Данные тестов и примера предназначены для проверки; это не актуальное предложение поставщика. Прямое подключение закрытого Telegram-канала не используется. Полноценный браузерный вход через OAuth потребует отдельного серверного сервиса — GitHub Pages не выполняет серверный код.
